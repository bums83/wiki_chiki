# ThreatSwarm

`ThreatSwarm` — это Claude Code plugin, который разворачивает 27 узкоспециализированных AI-агентов для полной автоматизации пентеста: разведка → эксплуатация → закрепление → расследование → отчёт.

Вместо ручного проведения каждого этапа вы даёте IP, запускаете `/threatswarm:engage`, и через час получаете готовые доказательства и CVSS-отчёт.

## Архитектура агентов

ThreatSwarm использует 27 агентов, каждый из которых специализируется на конкретной задаче в цепочке пентеста:
- разведка
- сканирование
- эксплуатация уязвимостей
- сбор учётных данных
- написание отчёта

Все агенты работают параллельно и координируются через единый orchestration layer.

## Методология и навыки

Агенты обучены на 754 навыках из библиотеки `Anthropic-Cybersecurity-Skills` и соотнесены с MITRE ATT&CK framework.

Это означает:
- агенты следуют профессиональной методологии, а не делают запросы «наугад»
- результат — структурированные доказательства и приоритизированные отчёты
- каждый этап пентеста задокументирован в терминах ATT&CK

## Безопасность: трёхуровневая проверка границ

Критически важная особенность — трёхуровневая система проверки границ, которая:
- жёстко ограничивает цели для каждого инструмента
- не может быть переопределена AI-агентом
- является детерминированной защитой, а не policy-решением

Это попытка решить проблему autonomous AI в безопасности: как дать агентам достаточно полномочий для работы, но не дать выйти за рамки.

## Полная цепочка

ThreatSwarm не останавливается на фазе эксплуатации. После получения доступа он:
1. автоматически закрепляется в системе
2. собирает улики
3. готовит финальный отчёт с CVSS-оценкой

## Использование

```bash
# Установка как Claude Code plugin
claude --plugin-dir ./threatswarm-plugin

# Запуск полного пентеста
/threatswarm:engage 10.10.10.5

# Запуск конкретного эксплойта после разведки
/threatswarm:attack 10.10.10.5 exploit CVE-2021-44228
```

ThreatSwarm естественно встраивается в llm-agents кластер:

## Ограничения

- Работает только с Claude Code (plugin API)
- Требует осмысленных целей и согласия на проведение пентеста
- Как и любой autonomous security tool — риск непредсказуемого поведения без должного контроля
