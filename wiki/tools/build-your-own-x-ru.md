# Build Your Own X — русский каталог

`Hordekiller/build-your-own-x-ru` — русскоязычный навигатор по учебным проектам, в которых технологию изучают через её самостоятельную реализацию: от shell и HTTP-сервера до базы данных, компилятора, рендерера и нейросети. Список заимствован из `codecrafters-io/build-your-own-x`; здесь добавлены русские страницы, тематические фильтры и ссылки на оригиналы.

**Это каталог обзоров, а не полный перевод всех учебников и не набор готовых production-компонентов.** Например, страница SQLite — короткое введение с фрагментом структуры записи и ссылкой на полный cstack tutorial; страница LLM содержит описание книги Себастьяна Рашки, оглавление и предпосылки. Глубину обучения и рабочий код следует искать в первоисточнике каждой карточки.

## Объём и темы

На проверенной ревизии программно подтверждены **359 записей, 359 уникальных ID, 359 HTML-страниц и 30 категорий**. Значение «41 язык» в README точнее понимать как **41 уникальную метку поля `lang`**: встречаются составные значения, например `C# / TypeScript / JavaScript`, а также `Node.js`.

Крупные разделы по данным индекса:

- веб-сервер — 73 материала;
- языки программирования — 41;
- игры — 34;
- блокчейн/криптовалюта — 21;
- операционные системы — 19;
- нейросети — 17;
- базы данных — 13;
- сетевой стек — 4, модели ИИ — 3.

Это классификация каталога, не оценка сложности и не гарантия полноты каждого направления. Метки `done` обозначают наличие русской страницы, а не прохождение урока пользователем или проверку правильности его кода.

## Как устроен сайт

Сервисная часть не нужна: готовые HTML/CSS и нативный JavaScript раздаются статическим хостингом. `assets/js/tutorials-ru.js` задаёт массив `window.TUTORIALS` с ID, категорией, языком, заголовком, URL оригинала и именем русской страницы. `main.js` строит карточки, фильтры, счётчики и поиск в браузере.

Поиск проверяет подстроку в **заголовке, категории и языке**, а не полный текст уроков. Заголовки в индексе преимущественно английские, хотя отдельные страницы имеют русские заголовки. Поэтому поиск русского перевода названия не обязательно найдёт нужную карточку. Фильтр по категории — отдельный механизм; фильтра по языку в рассмотренном UI-коде нет, язык можно включать в поисковый запрос.

`ru-done.json` и `ru_titles.json` служат вспомогательными списками ID и русских названий. Их наборы ID совпали с каталогом. Workflow `.github/workflows/deploy-pages.yml` загружает готовый репозиторий в GitHub Pages: отдельной сборки приложения или запуска тестов в нём нет.

## Применение: один механизм за итерацию

Практический способ использовать каталог — выбрать небольшой проект под конкретный пробел в знаниях, перейти к оригиналу, зафиксировать его версию и зависимости, а затем реализовать минимальный работающий механизм с собственными проверками.

- **Базы данных:** начать с REPL, сериализации записи и хранения страниц, затем изучать индекс. Это учебный разбор внутреннего устройства, а не альтернатива готовому backend вроде [PocketBase]({{ '/wiki/infra/pocketbase' | relative_url }}).
- **LLM:** использовать каталог для выбора материала о токенизации, attention или GPT. [Nanochat]({{ '/wiki/llm-agents/nanochat' | relative_url }}) — соседний путь к целостному training/evaluation pipeline; он не является переводом уроков этого каталога.
- **AI-assisted разработка:** в отличие от задачи «получи готовую реализацию», учебная задача требует самому объяснить инварианты и проверить изменения. В режиме [Вайб-кодинга]({{ '/wiki/llm-agents/vibe-coding' | relative_url }}) агент полезен как рецензент и помощник с тестами, но автоматически сгенерированный проект не доказывает понимание.

Такой порядок — рекомендация Wiki Chiki, а не обещанная авторами программа обучения. В каталоге нет общей проверки знаний, отслеживания личного прогресса или единого набора тестов для всех проектов.

## Локальный запуск

Для просмотра достаточно статического HTTP-сервера. Безопаснее явно ограничить его loopback-интерфейсом:

```bash
git clone https://github.com/Hordekiller/build-your-own-x-ru.git
cd build-your-own-x-ru
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8000/`. Локальный сервер не скачивает внешние уроки: оригиналы, видео и другие языковые версии остаются внешними ссылками. Страницы также подключают Google Fonts, поэтому локальная копия не равнозначна полностью автономной библиотеке.

## Проверка и ограничения

Рассмотрена ревизия `405fedc956856069e661fd900abb8dab69fb9984` ветки `main` от 2026-08-18. Архив именно этой ревизии извлечён локально; проверены все записи, существование целевых страниц, наличие H1 и ссылки на ожидаемый оригинал. Битых локальных `href` в страницах уроков не найдено. `node --check` прошёл для обоих JS-файлов; четыре проверки функции поиска/категории и четыре локальных HTTP smoke-запроса прошли.

Это **не** аудит качества переводов или кода всех уроков. Внешние URL массово не проверялись, примеры не компилировались, визуальное поведение в браузере не тестировалось. README заявляет Python-генератор и аудит `359/359`, но на проверенной ревизии Python-скриптов нет: собственные проверки Wiki Chiki не следует выдавать за запуск отсутствующего upstream-аудита.

README заявляет MIT для собственного кода и ссылается на `LICENSE` другого репозитория автора. В рассмотренном дереве отдельного файла лицензии нет, GitHub API вернул `license: null`. Это граница подтверждения лицензии, а не вывод о запрете использования. Права на оригинальные уроки и код нужно проверять отдельно; наличие русской страницы не перелицензирует исходный материал.
