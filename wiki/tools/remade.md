# Remade

[Remade](https://remade.wiki/explore/) — поддерживаемый сообществом каталог независимых реализаций существующего ПО и вспомогательных инструментов для них. Он помогает начать поиск от знакомого продукта или интерфейса: например, найти проекты, ориентирующиеся на Photoshop, Microsoft Project, AutoCAD, Discord или Windows.

Это **навигатор к кандидатам, а не проверенный рейтинг замен**. Remade не разрабатывает и не сопровождает перечисленные приложения; публикация карточки не подтверждает работоспособность, безопасность, полноту совместимости или юридическую чистоту реализации.

## Что находится в каталоге

На 2026-10-21 страница Explore и публичный JSON согласованно содержали **123 проекта и 13 supporting tools — 136 записей**. Числа относятся к снимку каталога, а не к стабильному размеру базы или количеству готовых продуктов.

- **Original** — исходная программа, интерфейс или протокол, на который ориентируется реализация. Несколько проектов могут иметь одну цель; один проект может охватывать несколько originals.
- **Project** — независимая реализация с заявленной целью воспроизведения поведения, интерфейса, форматов или совместимости. Более широкие альтернативы допускаются по отдельному решению редакторов.
- **Supporting tool** — launcher, интеграция, порт или другое дополнение к уже индексируемому проекту. Отмечается как Tool и не считается ещё одной реализацией оригинала.
- **Suite** — явно заданная группа проектов; сама по себе не является дополнительным приложением.
- **Project Request** — запрос на желаемую реализацию, а не существующее решение или обещание его разработать.

По policy основной фокус — программы, исходная реализация которых не опубликована как open source. Исключения требуют одобрения и раскрытия этой особенности. Форки самого оригинала, оболочки над его закрытым движком и простое визуальное сходство без содержательной цели совместимости обычно не подходят; для broader alternatives и supporting tools действуют отдельные правила.

## Как искать и читать карточку

Explore предлагает поиск и фильтры по категории, языку, платформе, статусу разработки и заявленной совместимости. Есть сортировка по дате добавления, алфавиту и GitHub stars. Категории покрывают creative, productivity, engineering, operating systems, games, developer tools, protocols и other.

Список записей доступен в исходном HTML без JavaScript; для фильтрации, сортировки и индексированного поиска нужен JS. Наличие элементов управления проверено по странице, но их браузерное E2E-поведение в рамках этого обзора не тестировалось.

В карточке проекта нужно читать не только описание, но и **Known limitations**, лицензию, платформы, ссылки на repository/docs и две независимые шкалы:

| Поле | Значения | Как трактовать |
|---|---|---|
| Development status | Planned, Experimental, Alpha, Beta, Stable, Archived | Стадия проекта; не общий результат тестирования качества |
| Compatibility | Targeting, Partial, High, Claimed Complete | Заявленная степень достижения цели, не измеренный Remade процент совместимости |

Сайт прямо помечает status и compatibility как **maintainer-reported**. `Claimed Complete` — не сертификат, а `Planned` может означать только исследования, планы и каркас репозитория. Например, карточка BeamCraft явно предупреждает об отсутствии пригодного для работы detailing-приложения. GitHub stars и недавний push тоже не доказывают пригодность к конкретному workflow.

## Практический маршрут выбора

Рекомендуемый порядок Wiki Chiki: выбрать оригинальный продукт → отфильтровать платформу → прочитать ограничения → перейти в репозиторий кандидата → проверить конкретный release и лицензию → воспроизвести свой сценарий на копии данных. Для миграции особенно важны импорт/экспорт реальных документов, сохранность свойств, автоматизация, производительность и возможность вернуться к исходному инструменту.

[Penpot]({{ '/wiki/tools/penpot' | relative_url }}) — пример отдельного design-продукта, который оценивают по collaboration, design systems, стандартам и deployment-модели. Remade находится раньше в процессе: помогает составить список кандидатов, но не заменяет такую предметную оценку. Эта связь не означает, что Penpot обязательно включён в каталог.

То же различие полезно для capture/editor-сценариев: статья об [OpenScreen]({{ '/wiki/tools/openscreen' | relative_url }}) разбирает конкретный инструмент и платформенные ограничения, тогда как запись в каталоге даёт лишь отправную точку для проверки альтернативы.

[Build Your Own X — русский каталог]({{ '/wiki/tools/build-your-own-x-ru' | relative_url }}) решает другую задачу: найти урок для самостоятельной реализации технологии. Remade помогает найти уже начатый проект вокруг конкретного продукта. Ни учебная реализация, ни карточка Remade не становятся production-ready заменой автоматически.

## Данные и участие

Источник каталога — YAML-записи в публичном репозитории `replicraft/remade`. Originals, projects, tools, suites и requests разделены; schema и проверки связей контролируют структуру, уникальность и ссылки между сущностями. Добавление проходит через pull request и review; issue с предложением не публикует карточку автоматически.

Для автоматизации доступны build-generated экспорты:

- [`/data/catalog.json`](https://remade.wiki/data/catalog.json) — originals, projects, tools, suites и featured; проверенный ответ имеет `schemaVersion: 1`.
- [`/data/requests.json`](https://remade.wiki/data/requests.json) — документированный экспорт запросов; его содержимое отдельно не проверялось.

Для внутреннего мониторинга можно сохранять датированные снимки JSON, сравнивать slug/repository/status/limitations и отправлять на review только изменения. Это рекомендация, а не настроенная в Wiki автоматизация. Public JSON удобнее извлечения карточек из HTML, но описания в нём остаются заявлениями каталога, а не независимыми результатами тестов.

## Лицензии и границы доверия

Репозиторий самого Remade содержит MIT License. **Она не распространяется автоматически на перечисленные приложения.** В policy допускаются отдельно одобренные `Unlicensed` проекты; текущая база содержит и явно обозначенный source-available проект с ограничительной лицензией. Поэтому README-формулировку про open-source directory нельзя читать как гарантию свободной лицензии каждой записи. `Unlicensed` и permissive `Unlicense` — разные вещи.

Clean-room — метод разработки, а не присваиваемый каталогом юридический статус. Remade не проводит независимый аудит происхождения кода и не гарантирует законность каждого проекта. Для использования, распространения и миграции следует отдельно проверять лицензионные условия, права на форматы/активы и применимое право.
