# Video Summary — генератор коротких видео-обзоров

Аналог NotebookLM Short Video Overviews для Hermes Agent.  
Превращает текст/ссылку/PDF в вертикальное видео (9:16, 1080×1920) с озвучкой.

## Возможности

- Приём текста, URL, PDF
- Генерация сценария через любую LLM (DeepSeek, GPT, Claude)
- Рендер кадров в стиле Dark Material через Pillow
- Озвучка через gTTS (Google, бесплатно, работает из РФ)
- Сборка MP4 через FFmpeg с посценовой синхронизацией
- Каждый кадр длится ровно столько, сколько его озвучка

## Установка

```bash
# Зависимости Python
pip install Pillow gTTS

# Системные (должны быть в Ubuntu/Debian)
sudo apt install ffmpeg
```

## Использование

### 1. Установка как навыка Hermes Agent

Скопируй папку `video-summary` в `~/.hermes/skills/creative/` и перезапусти Hermes.

### 2. Ручной запуск

```bash
# Сначала сгенерируй JSON-сценарий через LLM (см. промпт в references/)
# Затем:
python3 scripts/gen_video_summary.py --script-file /path/to/script.json
```

### 3. Через Hermes Agent

Просто скажи:
- «Сделай видео-обзор по статье https://...»
- «Сгенерируй видео по этому тексту»
- «Как NotebookLM, сделай шортс»

Агент сам: загрузит → сгенерирует сценарий → нарисует кадры → озвучит → соберёт MP4.

## Формат сценария (JSON)

```json
{
  "title": "Заголовок видео",
  "scenes": [
    {
      "title": "Заголовок кадра (до 28 символов)",
      "bullets": ["Тезис 1", "Тезис 2", "Тезис 3"],
      "audio": "Текст озвучки этой сцены (1-2 предложения)"
    }
  ]
}
```

**Важно:** у каждой сцены должно быть поле `audio` — отдельный текст для озвучки именно этого кадра. Не используй единый `overall_audio` — последний слайд останется без звука.

## Требования

- Python 3.8+
- FFmpeg
- Интернет (для gTTS)
- Шрифты: DejaVu или Ubuntu (есть в любой Ubuntu/Debian)

## Кастомизация

Цвета, шрифты, размеры кадров — в начале `gen_video_summary.py`:
```python
WIDTH, HEIGHT = 1080, 1920
BG_COLOR = (13, 13, 15)          # фон
TITLE_COLOR = (100, 181, 246)    # заголовки
TEXT_COLOR = (255, 255, 255)     # тезисы
```
