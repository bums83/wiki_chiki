# bums83/snowball

Forked Kotlin/JVM 21 hackathon project for a self-learning FMCG promotion agent. Inspected at revision `b055f34b781def1400bf05845b91118c4fa36e4d`.

## Source facts

- The agent selects exactly one discount from `0%`, `10%`, `20%`, or `30%` for a product/day/store scenario.
- A deterministic simulator produces the selected outcome; an evaluator counterfactually replays all four actions against the same scenario shock, calculates the oracle optimum and regret, and creates an immutable `PromotionCase`.
- Learner recomputes a durable `Lesson` from linked cases; later agent decisions retrieve up to three lessons before prompting the model.
- The repo has ports/adapters, JSON Schema contracts, `spotlessCheck`, and JUnit tests. It intentionally uses in-process transport, not Kafka, and no Spring framework.
- The supplied benchmark compares clean and trained xmemory instances on 50 held-out date-split scenarios with learning disabled in both arms. README reports 44% / 44.04 regret without memory versus 76% / 12.17 exact-key memory and 80% / 7.18 fallback-key memory. These are upstream artifacts, not independently rerun results.
