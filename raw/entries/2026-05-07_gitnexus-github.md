# abhigyanpatwari/GitNexus

Источник: https://github.com/abhigyanpatwari/GitNexus

Ключевые факты из репозитория и описания:
- GitNexus — client-side knowledge graph creator и code intelligence engine, который строит граф по репозиторию или ZIP-архиву прямо в браузере.
- Даёт интерактивный knowledge graph и встроенного Graph RAG Agent для анализа кода.
- Поддерживает два основных режима: CLI + MCP для локального индексирования и Web UI для быстрого просмотра/чата в браузере.
- В bridge mode `gitnexus serve` локальный сервер подключается к веб-интерфейсу без повторной загрузки или переиндексации.
- Генерирует контекстные файлы уровня репозитория, включая `AGENTS.md` и `CLAUDE.md`, а также repo-specific skills.
- Интегрируется с Claude Code, Cursor, Codex, Windsurf и OpenCode.
- Подходит для agentic development, code exploration и снижения риска blind edits за счёт более полного архитектурного контекста.
