# surrealdb/surrealdb

Источник: https://github.com/surrealdb/surrealdb

Ключевые факты из репозитория и описания:
- SurrealDB — multi-model база данных на Rust, которая объединяет document, graph, relational, time-series, geospatial и key-value модели.
- Поддерживает realtime и event-driven сценарии, а также full-text, vector и hybrid search.
- Может работать как backend-as-a-service за счёт встроенной auth и permission model.
- Доступен как single Rust binary: embedded, browser via WebAssembly, edge, self-hosted single node или distributed cluster.
- Подходит для data-intensive систем, knowledge graphs, AI-agent backends и realtime приложений.
- Дает row-level access control и SQL-like SurrealQL.
- Лицензия в README указана как BSL 1.1.
