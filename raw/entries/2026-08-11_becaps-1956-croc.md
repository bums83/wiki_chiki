## Confirmed mechanics from code and docs

- Go module source requires Go `1.25.0`; CI requests `^1.26.0`.
- CLI handles file(s)/folder, text, stdin/stdout, QR, resume and relay options. `send` description is explicitly “over the relay”.
- Default live flow has a relay address and optional IPv6 relay; local-only and custom relay/proxy modes are explicit flags.
- Code phrase is parsed into a room identifier and PAKE passphrase. `src/pakekey` uses identity-bound PAKE protocol v2, HKDF-SHA-256 and mutual confirmation; `src/crypt` includes authenticated encryption implementations.
- Unix secure mode prevents `--code` from placing the shared secret in the process list unless the user intentionally enables insecure classic mode. Documentation recommends `CROC_SECRET`.
- `croc relay` default ports are `9009,9010,9011,9012,9013`; CLI requires at least two configured ports. Docker/self-host docs include relay password configuration.
- `--store` is opt-in async transfer: files encrypt client-side, one verified download or 24-hour expiry, capability/bearer link, sender revoke receipt. Storage sees metadata necessary for transfer/quota enforcement; it does not receive decryption key from URL fragment.
- `croc-web` is separate Go binary with embedded React/Vite/WASM client, site/health/WebSocket bridge and optional stored-transfer service. Browser limitations are documented separately.
